# Memory Stamp

Android app: chụp ảnh với filter màu film, tự cắt thành tem có viền răng cưa, lưu ngay trong máy và xếp vào nhật ký theo lịch.

- Không cloud, không tài khoản: ảnh nằm trong bộ nhớ của app, có tùy chọn lưu thêm vào `Pictures/MemoryStamp`.
- 12 filter film (xem trực tiếp khi ngắm, vuốt để đổi) + hạt, viền tối, lóa sáng, dấu ngày.
- Sổ tay: dán tem, chữ, sticker lên trang, kéo/xoay/phóng, lưu ảnh hoặc chia sẻ.
- Thư gửi tương lai: niêm phong tới ngày chọn, nhắc bằng thông báo.
- Xuất/nhập sao lưu dạng `.zip`.

Font Nunito (SIL Open Font License). Icon và minh họa là thiết kế riêng.

Build: `./gradlew assembleRelease` (cần Android SDK 35, JDK 17). GitHub Actions build sẵn APK ở mỗi lần push.
